
## Nivel estratégico (site-wide)
| Documento	| Función | Status |
|-----------|---------|--------|
| Maintenance Policy	| Documento de más alto nivel; define la intención, alcance y reglas del sitio completo |  |
| Maintenance Strategy	 | Define el enfoque por clase de activo (mix de reactivo, preventivo, predictivo, etc.); se revisa cada 1–2 años |  |
| Asset Management Plan	| Marco más amplio (ISO 55001); el mantenimiento es una parte de él |  |
| Reliability Program Plan	| Metodología profunda (RCM, SAE JA1011) para activos críticos específicos |  |
| Maintenance Budget | Plan	Envolvente financiera: costos, headcount, contractors, inversión |  |
| Maintenance KPI Framework	| Define los indicadores (MTBF, MTTR, PM compliance, planned work ratio) y sus objetivos |  |

## Nivel táctico (por sistema o área)
| Documento	| Función | Status |
|-----------|---------|--------|
| Maintenance Program |	Paquete completo de requerimientos de mantenimiento para un sistema o work center |  |
| Maintenance Plan	| Detalla tareas, frecuencias, recursos y procedimientos para activos específicos |  |
| Maintenance Schedule	| Calendario o intervalo (tiempo/usos) de ejecución |  |
| Condition Monitoring Plan	| Define qué parámetros se monitorean, umbrales y frecuencia para CBM/PdM |  |
| Lubrication Plan / Lubrication Specification	| Plan específico de engrase: puntos, lubricante, intervalos |  |
| Spare Parts Strategy / Spare Parts | Plan	Inventario crítico, niveles min/max, lead times |  |
| Shutdown Plan / Turnaround | Plan	Planificación de paradas mayores y overhauls |  |
| Criticality Assessment / Risk Assessment	| Clasificación de criticidad de activos y análisis de riesgo |  |
| Failure Mode and Effects Analysis (FMEA)	| Identificación de modos de falla y sus efectos |  |
| Reliability Centered Maintenance (RCM) | Plan	Selección de tareas óptimas por modo de falla |  |

## Nivel operativo (por tarea o activo)
| Documento	| Función | Status |
|-----------|---------|--------|
| Standard Operating Procedure (SOP)	| Instrucciones paso a paso para una tarea de mantenimiento |  |
| Work Instruction	| Instrucción específica para una sub-tarea (más granular que un SOP) |  |
| Maintenance Procedure	| Procedimiento general de mantenimiento (preventivo, correctivo, de inspección) |  |
| Maintenance Checklist	| Lista de verificación de tareas para una inspección o servicio |  |
| Work Order Procedure	| Proceso de autorización, asignación y cierre de órdenes de trabajo |  |
| Operation and Maintenance (O&M) Manual	| Manual del OEM: especificaciones, intervalos, diagramas |  |
| Root Cause Analysis (RCA) Procedure	| Procedimiento para analizar fallas y prevenir recurrencia |  |
| Maintenance Training Plan	| Plan de desarrollo de competencias y certificaciones |  |
| Maintenance Audit Checklist	| Checklist de auditoría interna de cumplimiento |  |
| Maintenance Improvement Plan	| Plan de mejoras continuas (Kaizen, reliability improvement) |  |
| Maintenance Data Management Plan	| Gobernanza de datos: qué se registra, dónde, quién lo actualiza |  |
